# Dark Mode Toggle

**Date:** 2026-08-21
**Status:** accepted
**Author:** collaborative

## Context

HireHub is light-only. Users asked for a choice to turn dark mode on or off. Tailwind already defines `.dark` tokens in `index.css`. Most screens still use hardcoded `bg-white` / `slate` classes.

## Decision

- User toggle only (on/off). Do not follow the OS theme automatically.
- Persist `hirehub-theme` in `localStorage` (`light` or `dark`).
- Put `.dark` on `<html>` so Tailwind `dark:` variants work.
- Apply the class in `index.html` before React loads to avoid a light flash.
- Show the toggle in the sidebar (logged-in), the public header, and login/register.

## Alternatives Considered

- Follow `prefers-color-scheme` — rejected; the request was an explicit choice.
- Server-stored preference — extra API; localStorage is enough.

## Consequences

Refreshing keeps the last choice. Guests and signed-in users can both switch. After a `git push`, Render will rebuild the frontend.
